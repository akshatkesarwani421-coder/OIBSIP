# Calculator

A simple browser-based calculator made with HTML, CSS, and JavaScript.

## Features

- Number input from `0` to `9`
- Decimal number support
- Addition, subtraction, multiplication, and division
- Clear button
- Backspace button
- Division-by-zero error handling
- Rounded decimal results

## How to Run

1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to perform calculations.

No installation or additional packages are required.

## Evaluation Method

This calculator evaluates operations from left to right. For example, `2 + 3 × 4` gives `20` because it first calculates `2 + 3`, then multiplies the result by `4`.
