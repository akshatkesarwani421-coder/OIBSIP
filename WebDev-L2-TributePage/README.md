# Tribute to Dr. A.P.J. Abdul Kalam

A responsive tribute page about Dr. A.P.J. Abdul Kalam, his work in science, his time as President of India, and his encouragement of students.

## Features

- Biography and key moments timeline
- Verified quote with its source
- Responsive layout for smaller screens
- Locally stored photo with attribution

## Run

Open `index.html` in a browser, or use VS Code's Live Server.
